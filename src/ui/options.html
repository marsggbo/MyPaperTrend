⚙ MyPaperTrend Settings

Account & cloud sync

Sign in with GitHub to sync your history to the cloud — it creates (or forks) a mypapertrend-data repo under your account and writes one file per scholar. No manual token needed.

Tracking & auto-update

You track a scholar by flipping the Track switch on their profile page. Each tracked scholar is stored separately, so nobody's data mixes. Auto-update opens each tracked profile in a hidden background tab at the time below, records all their papers, and closes it — no scraping API needed (runs whenever the browser is open).

Storage

By default your data lives locally in this browser (no account needed). Optionally mirror it to a GitHub repo for backup, cross-device sync, or to feed a public dashboard. GitHub sync applies to your primary profile only.
Stored only in this browser. Never commit tokens into a repo.

Data source (advanced)

Default is reading your Scholar page directly — free and never blocked. You can add a paid API as a fallback (e.g. for background updates).
